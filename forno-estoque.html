Forno & Estoque.

Transformando uma necessidade real em tecnologia. Um sistema de gestão de insumos pensado para uma operação de pizzaria, com controle de saldos, regras de reposição e alertas automáticos pelo Telegram.

  • React
  • TypeScript
  • API REST
  • Supabase / PostgreSQL
  • Telegram Bot
  • Render

Do estoque manual à gestão inteligente

01 · ORGANIZAÇÃO

Cadastro de produtos, categorias e fornecedores, com controle das quantidades disponíveis, custos e movimentações.

02 · COMPRAS INTELIGENTES

Configuração de estoque mínimo e máximo. A lista de compras sugere as quantidades necessárias para reposição.

03 · ALERTAS AUTOMÁTICOS

Quando um insumo alcança o estoque mínimo, a integração com Telegram envia os saldos e a quantidade sugerida para compra.

O que desenvolvi

O projeto reúne frontend, API, banco de dados e automações numa ferramenta voltada à rotina de uma pizzaria. A proposta vai além do cadastro de produtos: ajuda a monitorar o que existe no estoque, identificar necessidades de reposição e organizar as próximas compras. O desenvolvimento também envolveu tecnologias de interface, regras de negócio, integração com Telegram, deploy e versionamento.

Este estudo de caso usa somente a apresentação visual e as informações fornecidas pelo autor. O repositório de desenvolvimento é privado; não publico aqui código-fonte, credenciais ou dados internos.
